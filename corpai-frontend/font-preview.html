como funciona o processo de escalação no turno noturno? preciso saber o SLA de resposta para incidentes P1 e quais canais são usados para notificação do líder.

L
liminai

O processo de escalação no turno noturno segue o fluxo abaixo:


1. Detecção do incidente: O alerta aciona o webhook que envia notificação via Telegram e e-mail para o líder de plantão.


2. SLA de resposta:

  • P1 (crítico): 15 minutos para primeira resposta
  • P3 (médio): 2 horas

Caso o SLA não seja cumprido, escale automaticamente via /api/escalation/override.
